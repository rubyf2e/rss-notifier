依 `copilot-instructions.md` 執行。

本次將所有 Backend HTTP API 統一加上 `/api` prefix，並同步更新：

- Backend routing
- `api.md`
- `postman/rss-notifier-api.postman_collection.json`

### API Prefix

所有目前 HTTP API：

```text
/
```

改為：

```text
/api/
```

例如：

```text
POST /auth/magic-link
→ POST /api/auth/magic-link

GET /auth/magic-link/verify
→ GET /api/auth/magic-link/verify

GET /subscriptions
→ GET /api/subscriptions

POST /subscriptions
→ POST /api/subscriptions

PATCH /subscriptions/:publicId/pause
→ PATCH /api/subscriptions/:publicId/pause

PATCH /subscriptions/:publicId/resume
→ PATCH /api/subscriptions/:publicId/resume

DELETE /subscriptions/:publicId
→ DELETE /api/subscriptions/:publicId

GET /subscriptions/unsubscribe
→ GET /api/subscriptions/unsubscribe
```

健康檢查也同步：

```text
GET /
→ GET /api/
```

### Backend

先檢查目前：

- `main.ts`
- Controller
- Module
- existing global prefix
- E2E tests
- Postman

找出目前 routing prefix 的設定方式。

優先使用 NestJS 現有的 global prefix 機制統一加入：

```text
/api
```

不要逐一修改每個 Controller 的 `@Controller()` path，除非目前架構無法使用 global prefix。

不要建立第二套 routing mechanism。

### 注意

不要讓 `/api/api/...` 發生。

確認目前沒有既有 prefix，或正確處理現有 prefix。

所有 API endpoint 最終只能有一個 `/api` prefix。
